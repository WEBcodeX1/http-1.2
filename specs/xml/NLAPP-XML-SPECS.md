# 4. Next Level Application Proxy Protocol (NLAPP)

## 4.1. Overview

This specification is currently under development.

Please refer to the [development status page](https://www.der-it-pruefer.de/network/Exemplary-HTTP-Processing-Protocol-Design) for the latest updates.

## 4.2. Scaling

> [!NOTE]
> NLAPP server responses will include scaling-friendly codes and indicators (for example, limit exhaustion and fine-grained percentage-based load statistics) to support request propagation and delegation to less frequented servers.
