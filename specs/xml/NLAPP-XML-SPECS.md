# 4. Next Level Application Proxy Protocol (NLAPP)

## 4.1. Overview

This specification is currently under development.

Please refer to the [development status page](https://www.der-it-pruefer.de/network/Exemplary-HTTP-Processing-Protocol-Design) for the latest updates.

## 4.2. Scaling

> [!NOTE]
> NLAP servers response messages will include scaling-friendly codes / indicators (e.g. limit-exhaustion and/or fine grained percentual load statistics) for propagating decisions / delegating the request to less-frequented servers.
